# NBA Player Scraper - Usage Guide\n\n## Overview\n\nThe NBA Player Scraper is a production-ready Node.js application that scrapes player data from https://www.nba.com/players and extracts comprehensive career statistics from individual player profiles.\n\n### Key Features\n- ✅ **Career Statistics Focus**: Extracts TOTAL career games played (not season GP)\n- ✅ **Complete Player Profiles**: Scrapes individual player pages for detailed stats\n- ✅ **Structured Data Format**: Stores data in JSON with consistent schema\n- ✅ **Performance Optimized**: Controlled concurrency and retry logic\n- ✅ **Error Handling**: Robust error handling with fallback mechanisms\n- ✅ **RESTful API**: Multiple endpoints for data access and management\n\n## Quick Start\n\n### 1. Start the Server\n`bash\ncd api\nnpm run dev\n`\n\n### 2. Start Scraping\n`bash\n# Using cURL\ncurl -X POST http://localhost:3001/api/manual/scrape-nba\n\n# Or use any HTTP client like Postman\nPOST http://localhost:3001/api/manual/scrape-nba\n`\n\n### 3. View Results\n`bash\n# Get all players\ncurl http://localhost:3001/api/manual/players\n\n# Get statistics summary\ncurl http://localhost:3001/api/manual/stats\n`\n\n## API Endpoints\n\n### Core **gamesPlayed**: Total career games, NOT current season\n- Scraper visits each player's individual profile page\n- Extracts career totals from \"Career Stats\" section\n- Fallback mechanisms for different page layouts\n\n### ✅ Performance Optimization\n- Controlled concurrency (5 players at a time)\n- Request delays to avoid server overload\n- Retry mechanism for failed requests\n- Timeout handling\n\n### ✅ Error Handling\n- Individual player failures don't stop the entire process\n- Fallback data for players with missing stats\n- Comprehensive logging\n- Graceful degradation\n\n### ✅ Data Persistence\n- Automatic backup of existing data\n- Timestamped backups\n- JSON file storage\n- Data validation\n\n## Testing\n\nRun the comprehensive test suite:\n\n`bash\ncd api\nnode src/test/test-nba-scraper.js\n`\n\nThe test suite covers:\n- Server health checks\n- Scraping functionality\n- Data validation\n- API endpoints\n- Search functionality\n- Error handling\n\n## Performance Expectations\n\n- **Total Players**: ~450+ active NBA players\n- **Scraping Time**: 3-5 minutes (depends on network)\n- **Success Rate**: 95%+ (with fallbacks for failures)\n- **Memory Usage**: ~50-100MB during scraping\n- **Storage**: ~5-10MB JSON file\n\n## Troubleshooting\n\n### Common Issues\n\n1. **Scraping Takes Too Long**\n - This is normal! The scraper visits 450+ individual player pages\n - Expected duration: 3-5 minutes\n - Check logs for progress updates\n\n2. **Some Players Missing Stats**\n - NBA.com structure variations\n - Rookie players with limited data\n - Players with unusual page layouts\n - These players get gamesPlayed: 0 as fallback\n\n3. **Request Timeouts**\n - Server temporarily unavailable\n - Network issues\n - Retry mechanism will attempt 3 times\n\n4. **Memory Issues**\n - Large number of concurrent requests\n - Reduce concurrencyLimit in service\n - Increase Node.js memory: `node --max-old-space-size=4096`\n\n### Debugging\n\nEnable detailed logging:\n`bash\n# Check server logs\ntail -f api/logs/scraper.log\n\n# Check individual player scraping\n# The service logs each player processed\n`\n\n## Customization\n\n### Modify Concurrency\nEdit `manual.service.js`:\n`javascript\nthis.concurrencyLimit = 3; // Reduce for slower connections\nthis.requestDelay = 1000;   // Increase delay between requests\n`\n\n### Add New Fields\nExtend the player schema in `extractPlayerDetails()` method.\n\n### Change Data Storage\nReplace file storage with database in `savePlayersData()` method.\n\n## Production Deployment\n\n1. **Environment Variables**\n `bash\n   NODE_ENV=production\n   PORT=3001\n   `\n\n2. **Process Manager**\n `bash\n   # Using PM2\n   pm2 start src/server.js --name \"nba-scraper\"\n   `\n\n3. **Scheduled Scraping**\n `bash\n   # Cron job for daily updates\n   0 2 * * * curl -X POST http://localhost:3001/api/manual/scrape-nba\n   `\n\n## Support\n\nFor issues or questions:\n1.
